# Fictional demo inputs

All records in this directory were created for this portfolio demonstration. Names, stable IDs and `example.test` addresses do not identify real people. No challenge rows or sample answers were copied into these fixtures.

`dataset/` contains six requests, identity snapshots and a timestamped email change, minimal policy rules, an empty activity stream, and a manifest referencing JSON readbacks, a SQLite-compatible SQL export, a lookup log and a future JSON snapshot. Expected outcomes are documented in the root README and asserted independently in `code/tests/test_portfolio.py`.

The fixtures demonstrate supported schemas and decision boundaries; they are not representative performance benchmarks or evidence of real-world accuracy.
